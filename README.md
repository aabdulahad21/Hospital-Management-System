# Hospital Management System

A hospital management application developed using Java and Spring Boot to manage patient and hospital-related information. The project demonstrates backend development using REST APIs, database integration, and layered application architecture.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## Features

- Patient management
- Add, update, view, and delete patient records
- RESTful API endpoints for patient operations
- Database persistence using MySQL
- Object-relational mapping using JPA and Hibernate
- Layered architecture using Controller, Service, and Repository layers

## Project Structure

- **Controller** – Handles HTTP requests and REST API endpoints
- **Service** – Contains application/business logic
- **Repository** – Handles database operations using Spring Data JPA
- **Entity** – Defines the application's database entities

## Getting Started

### Prerequisites

- Java JDK
- MySQL
- Maven
- IntelliJ IDEA or another Java IDE

### Setup

1. Clone the repository.

2. Create a MySQL database for the application.

3. Configure the database connection in:
   
   `src/main/resources/application.properties`

4. Update the database username and password according to your MySQL configuration.

5. Run the application using your IDE or Maven.

6. The application will start on the configured Spring Boot port.
